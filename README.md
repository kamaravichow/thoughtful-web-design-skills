# Thoughtful web design

A collection of agent skills for landing pages and marketing sites that
feel built for a specific audience — not generic SaaS templates.

## Skills

| Folder | Use when |
|--------|----------|
| [thoughtful-design](thoughtful-design/) | Mood-first identity, Pexels + palette-from-photos, Frankenstein flow, motion as brand |
| [landing-page-design-101](landing-page-design-101/) | Conversion-first critique: clarity over spectacle, performance as a design constraint |

To add another skill, create a sibling folder with its own `SKILL.md`:

```
thoughtful-design/
another-skill/
```

## Use in Cursor

Copy a skill folder into `~/.cursor/skills/<name>/`, or attach
`@thoughtful-design` from this repo.

```bash
cp -R thoughtful-design ~/.cursor/skills/thoughtful-design
```
